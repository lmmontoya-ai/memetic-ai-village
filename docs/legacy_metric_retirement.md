# Legacy v1 metric retirement

**The AI Village export is used to identify and characterize operational epistemic cascades; only randomized experiments are used to estimate causal peer influence.**

Files created by the original feasibility pipeline are retained for reproducibility and must be read
as **LEGACY V1 — INVALID PROXY** when they contain any of the following:

| Legacy item | Why invalid | V2 replacement |
| --- | --- | --- |
| First-later-decision graph | Evaluates an arbitrary action rather than the candidate response | Response-specific eligibility |
| `probable exposure` | Channel compatibility was described too strongly | `eligible`, never “probably seen” |
| `candidate transmission` | Lexical recurrence does not establish proposition identity or uptake | L0 cross-agent lexical recurrence |
| First later tool call | Usually unrelated to the claim | Human-adjudicated claim-relevant action window |
| Cumulative-memory overlap | Long cumulative text creates nonspecific matches | Before/after memory delta |
| Same-agent lexical recurrence | Does not ensure endorsement or a new recipient | Structurally valid third-party expression candidate plus adjudication |
| Global source shuffle | Destroys local room, task, time, and artifact confounds | Fixed-author local comparisons and hard matched controls |
| Author-label permutation as a social-influence null | Changes which fixed lexical pairs qualify as cross-agent | Retained only as an author-autocorrelation diagnostic; excluded from Gate 1 |
| V1 full-go gate | Relied on unattainable prompt inclusion and invalid proxies | Reliability and matched-control Gate 1 |

The v1 counts `56/60`, `59/60`, and `38/60`, and the unadjudicated 60-case distribution are not
substantive findings. V2 report generation must fail if it attempts to emit them as evidence.

Repository terminology checks allow a retired phrase only in the frozen v1 plan/specification,
historical v1 reports, this retirement document, or text explicitly containing `LEGACY V1` or
`invalid proxy` in the same paragraph/table row.
