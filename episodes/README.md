# Local episode artifacts

The pipeline writes candidate registries, development units, truth-audit sheets, and case bundles here. These can contain raw excerpts or reveal annotation assignments, so they are excluded from public Git.

Public readers should use the [current results](../reports/machine_annotation_preliminary_v2_2.md) and [reviewer guide](../docs/reviewer_guide.md). Approved reviewers can regenerate local evidence as described in the [reproduction guide](../docs/reproduction.md).
